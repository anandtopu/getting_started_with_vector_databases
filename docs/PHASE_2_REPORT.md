An earlier diagnostic fixture run exposed duplicate/numerical ties. The primary recall metric now accepts equivalent kth-boundary neighbors while still requiring closer ones; strict ID recall remains in every new run. An earlier catalog run used a relevance rule that penalized unrequested colors. That rule was corrected; old raw files remain isolated by query hash and metric semantics. They were not rewritten to improve the table.

## Unverified or blocked

1. **Container runtime:** the default desktop-linux context points to an unavailable Docker Desktop pipe. A separate working Podman 6.0.2 context pulled the pinned PostgreSQL image but failed before startup with `netavark: nft did not return successfully while applying ruleset`. The isolated `marlowe-vector-course-check` container/network/volume were removed. Other profiles were structurally checked but not started after the shared networking failure. All-profile runtime compatibility remains open; no host firewall changes were made.
2. **Remote CI:** workflow definitions exist, but no GitHub remote or hosted run was available. Windows local results do not prove Linux/macOS CI or Linux service-container tests. Qdrant/pgvector tests are native smoke tests, not full server adapter certification.
3. **Image/LLM inference:** SigLIP and Ollama helpers have explicit cache/download boundaries and pinned identities, but their actual weights/generation were not run in this phase. MiniLM was exercised. Image-quality and generation evaluations remain with their application lessons.
4. **Later scope:** no claim that planned modules, ANN indexes, managed engines, production operations, complete glossary/cheatsheets, or capstones are finished. Feature-map lesson rows still require their tier deliverables.
5. **Validation limits:** online links were researched selectively; a repository-wide external-link crawl and fresh pip-only installation were not run. The pip file is exported from the tested lock. Playground was tested through Streamlit's interaction runner, not a visual browser inspection. The data is synthetic and has not been human relevance judged.

The Phase 2 local foundation gate is met with these explicit environment gaps. Next is Phase 3: complete Tier 1 modules 00–04, their examples, exercises/solutions, notebooks, quizzes, and checkpoint.
