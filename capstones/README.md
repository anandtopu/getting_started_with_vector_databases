# Capstones

Choose one after its prerequisite tier, or complete all five. Each package contains a runnable baseline, a full reference workflow, an acceptance contract, a scored rubric, architecture and extension ideas. Start by running the starter smoke check; acceptance is expected to fail until you implement its contract.

- [Build a durable indexed TinyVec](01_tinyvec/README.md)
- [Choose a database with evidence](02_database_bakeoff/README.md)
- [A cited help assistant](03_rag_assistant/README.md)
- [Operate isolated seller search](04_multitenant_search/README.md)
- [Ship a complete Marlowe Search demo](05_marlowe_search/README.md)

The measured references are local teaching experiments. Read [the final audit](../docs/DEFINITION_OF_DONE.md) before treating any component as production ready.
