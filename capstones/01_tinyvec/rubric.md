# Rubric (100 points)

| Criterion | Points | Evidence |
|---|---:|---|
| Contract correctness | 30 | All project acceptance checks pass against the learner file |
| Data and evaluation | 25 | Same dataset/query IDs, exact ground truth or judged relevance, recorded sample sizes |
| Failure behavior | 20 | Exercise the failure boundaries in architecture.md; show a failing case and recovery |
| Reproducibility | 15 | Locked environment, runnable command, raw result and honest limits |
| Explanation | 10 | Defend the trade-off and one rejected alternative with evidence |

Passing target: 80/100, with no isolation violation, invented measurement or silent failure. A fast result cannot compensate for incorrect answers or lost data that is concealed. Starter smoke alone earns no correctness points. Native setup is optional for learning but required before claiming native completion.
