# Code of conduct

Help people learn. Treat questions as sincere, explain unfamiliar terms, and criticize ideas and code with evidence. Respect differences in experience, language, identity, and hardware access.

Harassment, threats, discriminatory remarks, sexualized attention, doxxing, and publication of private information are unacceptable. Respect requests to stop contacting someone.

Maintainers may remove harmful contributions and restrict participation. They should explain decisions where appropriate, protect report privacy, and apply these standards consistently. If a concern involves a maintainer, contact another maintainer privately through the repository host when available. This local project has no dedicated reporting mailbox yet; do not post sensitive reports publicly.

These expectations apply to discussions, reviews, issues, and events where someone represents the project.
